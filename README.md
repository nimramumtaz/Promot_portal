# Prompt Engineering Competition Portal

1. Open this folder in VS Code, then open the terminal (Ctrl + `).
2. `npm install`
3. `npm start`  (or `npm run dev` to auto-restart on changes)
4. Site: http://localhost:3000   Admin: http://localhost:3000/admin.html

Admin password: set `ADMIN_PASSWORD` (default `admin123`). PowerShell: `$env:ADMIN_PASSWORD="mypass"; npm start`
Registrations are saved in `data/registrations.json`.
Hero photo: put your campus image at `public/images/hero.jpg`.
Edit date, venue, account details and email at the top of the script in `public/index.html` (CONFIG).
